# BSP 代码校验检查清单

## 使用方法

当用户要求校验 BSP 代码时，逐项检查以下内容。
需要同时具备：原理图信息 + 芯片手册 + 待校验代码。

---

## 1. 引脚分配校验

对代码中每个引脚配置：

- [ ] **引脚号一致**：代码中的引脚号 == 原理图连接的引脚号
- [ ] **AF 编号正确**：代码中的 AF 值 == 手册引脚复用表中该功能的 AF 值
- [ ] **方向正确**：
  - 输出信号 → 推挽/开漏（根据总线类型）
  - 输入信号 → 输入模式
  - 双向信号（I2C）→ 开漏
  - 模拟信号 → 模拟模式
- [ ] **上下拉正确**：
  - 外部有上拉 → 代码应设 NOPULL
  - 无外部上拉且需要 → 代码应设内部上拉
  - 推挽输出 → 通常 NOPULL
- [ ] **速度合理**：
  - 高频信号（SPI CLK > 10MHz）→ HIGH/VERY_HIGH
  - 低频信号（I2C 100k/400k）→ MEDIUM 即可
  - 不必要的 VERY_HIGH 增加 EMI

## 2. 时钟配置校验

- [ ] **外设时钟已使能**：对应 RCC 寄存器/函数已调用
- [ ] **GPIO 端口时钟已使能**：使用的每个 GPIO 端口
- [ ] **时钟频率在范围内**：
  - APB1 外设: 通常 ≤ max_freq/2
  - APB2 外设: 通常 ≤ max_freq
- [ ] **波特率/频率计算正确**：
  - UART: BRR 值 vs 期望波特率
  - SPI: 分频系数 vs 期望 CLK 频率
  - I2C: 时钟配置 vs 期望速度（100k/400k/1M）

## 3. 外设配置校验

### UART/USART
- [ ] 波特率匹配通信对端需求
- [ ] 数据位/停止位/校验位一致
- [ ] 硬件流控引脚（如使用）已配置
- [ ] FIFO/DMA 配置（如使用）正确

### I2C
- [ ] 主从模式正确
- [ ] 速度模式（Standard/Fast/Fast+）匹配器件要求
- [ ] 从设备地址（7bit/10bit）正确
- [ ] 超时处理存在

### SPI
- [ ] 主从模式正确
- [ ] CPOL/CPHA 匹配器件要求（查器件手册时序图）
- [ ] 数据位宽正确（8/16 bit）
- [ ] CS 管理方式（硬件/软件）正确
- [ ] MSB/LSB first 正确

### ADC
- [ ] 参考电压正确
- [ ] 采样时间满足信号源阻抗要求
- [ ] 通道映射正确（引脚 → ADC 通道号）
- [ ] 分辨率设置正确

### Timer/PWM
- [ ] 预分频和自动重装值 → 正确频率
- [ ] 通道极性正确
- [ ] 死区时间（互补 PWM）安全

## 4. 中断配置校验

- [ ] 中断优先级合理（高频中断 > 低频中断）
- [ ] NVIC 中断使能已调用
- [ ] 中断处理函数中清除了标志位
- [ ] DMA 中断和外设中断不冲突

## 5. DMA 配置校验

- [ ] DMA 通道/流 分配无冲突
- [ ] 传输方向正确（外设→内存 / 内存→外设）
- [ ] 数据宽度匹配（字节/半字/字）
- [ ] 循环模式 vs 单次模式选择合理
- [ ] 缓冲区对齐满足 DMA 要求

## 6. 安全性检查

- [ ] 看门狗配置（如果硬件有 WDG）
- [ ] 低功耗模式下引脚状态不会造成漏电
- [ ] 未使用引脚处理（设为模拟输入最省电）
- [ ] 总线冲突检测（同一 I2C 总线地址不重复）
